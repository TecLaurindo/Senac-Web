# Banco Web

Um sistema bancário web desenvolvido com HTML, CSS e JavaScript puro.

## Funcionalidades Implementadas

### 1. Autenticação
- Cadastro de nova conta corrente
- Login com email e senha
- Persistência de dados no localStorage

### 2. Operações Bancárias
- **Depósito**: Taxa de 7% sobre o valor depositado
- **Saque**: Taxa de 70% sobre o valor sacado
- Visualização do saldo em tempo real

### 3. Sistema de Empréstimos
- Solicitação de empréstimo personalizado
- Controle de empréstimos ativos
- Pagamento de parcelas
- Visualização de parcelas em aberto

### 4. Histórico
- Registro de todas as transações
- Detalhes de taxas aplicadas
- Filtro por tipo de operação

## Como Executar

1. Baixe todos os arquivos
2. Abra `index.html` em um navegador web moderno
3. Crie uma nova conta ou faça login
